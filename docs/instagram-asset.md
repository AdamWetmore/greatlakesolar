# Instagram glyph

`public/Instagram_Glyph.svg` is the unmodified `Instagram_Glyph_White.svg`
from Meta's `IG_brand_asset_pack_2023.zip`, downloaded November 10, 2026
from the logo-pack link on the current official brand page:
https://www.meta.com/brand/resources/instagram/instagram-brand/

`public/Instagram_Glyph_Black.svg` is the unmodified black SVG from the same
official pack, downloaded November 16, 2026. The shared `InstagramIcon` displays
these files directly as background images, without tinting or masking. The footer
uses black in system light mode and white in system dark mode. The contact card
uses black because its icon tile remains light. Dimensions remain 32px in the
footer and 40px in the contact card. Accessible names come from the links/text.

Meta's detailed Brand Elements page still required login on November 16, 2026.
Using the supplied black and white files avoids relying on third-party advice
about custom recoloring. See [the footer brand review](social-brand-review.md)
for the official sources, implementation checks, and verification limits.
